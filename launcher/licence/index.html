Пользовательское соглашение

Ознакомьтесь с условиями использования Founders Launcher перед продолжением установки и запуска игры.

1. Общие положения

1.1. Настоящее Пользовательское соглашение (далее — «Соглашение») определяет условия использования программного обеспечения Founders Launcher (далее — «Лаунчер»).

1.2. Лаунчер предназначен для подготовки, установки, обновления и запуска игровой сборки Minecraft, связанной с проектом Founders Create SMP.

1.3. Оператором Лаунчера является лицо или организация, указанные в разделе 13 настоящего Соглашения (далее — «Оператор»).

1.4. Использование Лаунчера допускается после ознакомления с настоящим Соглашением и его принятия пользователем.

1.5. Если пользователь не согласен с обязательными условиями, он должен отказаться от продолжения установки или использования Лаунчера.

2. Назначение Лаунчера

2.1. Founders Launcher может предоставлять следующие возможности:

  • Авторизацию пользователя через Discord.
  • Получение информации об игровой сборке.
  • Загрузку необходимых игровых компонентов.
  • Установку и обновление модификаций.
  • Проверку целостности игровых файлов.
  • Запуск поддерживаемой версии Minecraft.
  • Отображение состояния установки и обновлений.

2.2. Перечисленные возможности могут внедряться постепенно. Наличие функции в настоящем Соглашении не означает, что она уже доступна в текущей версии Лаунчера.

2.3. Лаунчер является самостоятельным программным продуктом проекта Founders Create SMP и не является официальным продуктом Mojang или Microsoft.

3. Учётная запись и авторизация

3.1. Для доступа к отдельным функциям Лаунчера может требоваться авторизация через Discord.

3.2. Авторизация выполняется с использованием официального механизма Discord OAuth.

3.3. Пользователь самостоятельно отвечает за безопасность своей учётной записи Discord и сохранность средств доступа к ней.

3.4. Лаунчер не должен запрашивать пароль от Discord непосредственно в собственном интерфейсе авторизации.

3.5. Пользователь обязуется не использовать чужие учётные записи без разрешения их владельцев.

4. Установка игровых компонентов

4.1. Для работы игровой сборки Лаунчеру может потребоваться загрузка и установка дополнительных компонентов, включая:

  • Совместимую среду выполнения Java.
  • Файлы Minecraft.
  • Загрузчик модификаций NeoForge.
  • Модификации и библиотеки.
  • Конфигурации и дополнительные игровые ресурсы.

4.2. Перед установкой пользователь должен иметь достаточное свободное место на накопителе и соответствующую конфигурацию компьютера.

4.3. Лаунчер должен выполнять операции с файлами в пределах предусмотренных для установки и обновления каталогов.

4.4. Пользователю рекомендуется сохранять резервные копии собственных миров, настроек и других важных файлов перед существенными обновлениями сборки.

4.5. Установка и использование Minecraft, NeoForge и сторонних модификаций регулируются также применимыми условиями их правообладателей.

5. Правила использования

5.1. Пользователь обязуется использовать Лаунчер законным способом и не нарушать права других лиц.

5.2. Запрещается:

  • Использовать Лаунчер для получения несанкционированного доступа к чужим аккаунтам.
  • Намеренно нарушать работу серверной инфраструктуры проекта.
  • Распространять вредоносные версии Лаунчера под видом официальных.
  • Использовать автоматизированные запросы для перегрузки сервисов проекта.
  • Обходить технические ограничения с целью причинения вреда проекту или другим пользователям.

5.3. Использование Лаунчера не освобождает пользователя от соблюдения правил игрового сервера Founders Create SMP.

6. Обновления

6.1. Оператор может выпускать обновления Лаунчера и игровой сборки для исправления ошибок, повышения безопасности и добавления новых возможностей.

6.2. Некоторые обновления могут быть необходимы для совместимости с игровым сервером.

6.3. Во время обновлений отдельные функции могут быть временно недоступны.

6.4. Лаунчер может проверять наличие новых версий через серверы проекта.

7. Обработка данных

7.1. При использовании Discord OAuth Лаунчер может получать сведения в пределах разрешений, предоставленных пользователем при авторизации.

7.2. В зависимости от фактической реализации это могут быть:

  • Discord ID пользователя.
  • Отображаемое имя.
  • Имя пользователя Discord.
  • Ссылка или идентификатор аватара.
  • Технические данные авторизованной сессии.

7.3. Для работы приложения могут обрабатываться технические сведения, необходимые для авторизации, доставки обновлений, обеспечения безопасности и диагностики ошибок.

7.4. Сведения о целях обработки, правовых основаниях, сроках хранения, получателях данных и правах пользователей должны быть представлены в отдельной политике конфиденциальности.

7.5. Принятие настоящего Соглашения само по себе не заменяет отдельное согласие на обработку персональных данных в случаях, когда такое согласие требуется применимым законодательством.

Конфиденциальность: перед публикацией необходимо указать действующую политику конфиденциальности, сведения об операторе данных и контакты для обращений пользователей.

8. Безопасность

8.1. Оператор стремится обеспечивать безопасность официальных версий Лаунчера и связанных с ним сервисов.

8.2. Пользователю рекомендуется скачивать Лаунчер только из официальных источников, опубликованных проектом.

8.3. Пользователь не должен передавать третьим лицам токены авторизации, пароли и другие секретные данные.

8.4. При обнаружении подозрительной активности пользователь может обратиться к администрации проекта.

9. Доступность сервиса

9.1. Лаунчер и связанные с ним сервисы могут быть временно недоступны из-за технического обслуживания, обновлений или непредвиденных сбоев.

9.2. Оператор вправе изменять функциональность Лаунчера, прекращать поддержку устаревших версий и выполнять необходимые технические работы.

9.3. О существенных изменениях пользователи могут уведомляться через интерфейс Лаунчера или официальные ресурсы проекта.

10. Ответственность

10.1. Лаунчер предоставляется в состоянии, соответствующем его текущей стадии разработки.

10.2. В предварительных версиях Alpha возможны ошибки, неполная функциональность и временные ограничения.

10.3. Оператор не гарантирует абсолютную бесперебойность работы программного обеспечения.
