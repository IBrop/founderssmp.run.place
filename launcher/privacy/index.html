Кратко о главном

Founders Launcher использует Discord OAuth2 для идентификации пользователя. Авторизация происходит через Discord, поэтому вводить пароль Discord непосредственно в лаунчер не требуется.

Мы стремимся обрабатывать только те сведения, которые необходимы для авторизации, сохранения аккаунта, безопасности и работы сервиса.

1. Общие положения

Настоящая Политика конфиденциальности описывает обработку персональных данных пользователей программного обеспечения Founders Launcher, связанного с проектом Founders SMP.

Политика распространяется на обработку данных при авторизации, использовании приложения, взаимодействии с серверной инфраструктурой и обращении в поддержку.

Сторонние сервисы, включая Discord, могут обрабатывать данные согласно собственным правилам конфиденциальности.

3. Какие данные мы обрабатываем

В зависимости от используемых функций Founders Launcher могут обрабатываться следующие категории данных.

Категория Данные Назначение
Discord ID Уникальный идентификатор аккаунта Идентификация пользователя
Discord Username Имя пользователя Discord Отображение аккаунта
Global Name Отображаемое имя Discord Персонализация интерфейса
Аватар Идентификатор изображения профиля Отображение профиля
Данные авторизации Сведения о сессии и необходимые OAuth-токены Поддержание авторизованного входа
Сведения о членстве Статус участия в Discord-сервере проекта Проверка условий доступа
Технические данные Сведения о запросах, ошибках и безопасности Защита и диагностика сервиса

Если пользователь предоставляет дополнительные сведения при обращении в поддержку, они могут обрабатываться для рассмотрения обращения.

Адрес электронной почты Discord может обрабатываться, если он предоставлен в рамках запрошенных разрешений OAuth и используется серверной частью приложения.

4. Авторизация через Discord

Founders Launcher использует протокол OAuth2, предоставляемый Discord.

При авторизации пользователь перенаправляется в интерфейс Discord для подтверждения необходимых разрешений.

После успешной авторизации серверная часть Founders Launcher может получить разрешённые данные профиля через Discord API.

Пароль Discord не требуется вводить непосредственно в Founders Launcher.

Пользователь может управлять разрешениями подключённых приложений в настройках своего аккаунта Discord.

Политика конфиденциальности Discord: discord.com/privacy

5. Цели и правовые основания обработки

Персональные данные могут использоваться для:

  • Авторизации и идентификации пользователя.
  • Сохранения и восстановления аккаунта.
  • Отображения имени и данных профиля.
  • Проверки разрешений на доступ.
  • Предотвращения несанкционированного доступа.
  • Поддержания стабильности и безопасности сервиса.
  • Обработки обращений пользователей.
  • Соблюдения применимых юридических обязательств.

В зависимости от конкретной операции правовым основанием обработки может выступать необходимость исполнения соглашения с пользователем, выполнение юридических обязанностей, законный интерес оператора или согласие пользователя, когда оно необходимо.

Пользователь может запросить информацию о правовом основании конкретной операции обработки.

6. Хранение данных

Данные аккаунта могут храниться в серверной инфраструктуре Founders Launcher, а также локально на устройстве пользователя для восстановления состояния приложения.

К локально сохраняемым сведениям могут относиться идентификатор Discord, имя пользователя, отображаемое имя и сведения об активном аккаунте.

Данные авторизации должны обрабатываться с использованием мер защиты, соответствующих их чувствительности.

Точные места хранения, поставщики инфраструктуры и страны обработки должны соответствовать фактической конфигурации сервиса.

7. Безопасность данных

При обработке персональных данных применяются технические и организационные меры, направленные на предотвращение несанкционированного доступа, утраты, изменения или раскрытия информации.

Такие меры могут включать:

  • Использование защищённых HTTPS-соединений.
  • Контроль доступа к серверным компонентам.
  • Ограничение доступа к служебным данным.
  • Защиту OAuth-токенов и конфиденциальных ключей.
  • Проверку авторизованных сессий.
  • Обработку ошибок без раскрытия секретных данных.

Несмотря на принимаемые меры, абсолютная безопасность передачи и хранения информации не может быть гарантирована.

8. Передача данных третьим лицам

Для функционирования Founders Launcher могут использоваться сторонние технические сервисы, включая Discord и поставщиков серверной инфраструктуры.

Данные могут передаваться таким поставщикам в объёме, необходимом для предоставления соответствующих услуг.

Данные также могут раскрываться при наличии действительного юридического обязательства.

Международная передача персональных данных, если она осуществляется, должна сопровождаться предусмотренными законодательством гарантиями.

9. Сроки хранения

Данные аккаунта хранятся не дольше, чем это необходимо для целей их обработки, с учётом действующих юридических обязательств.

Срок хранения отдельных категорий данных может зависеть от активности аккаунта, состояния сессии, необходимости обеспечения безопасности и установленных законом сроков.

По достижении цели обработки данные удаляются или обезличиваются, если дальнейшее хранение не требуется по законным основаниям.

10. Права пользователя

В пределах применимого законодательства пользователь может иметь право:

  • Получить информацию об обработке своих данных.
  • Запросить доступ к персональным данным.
  • Потребовать исправления неточных сведений.
  • Запросить удаление данных.
  • Потребовать ограничения обработки.
  • Возразить против определённых видов обработки.
  • Получить данные в переносимом формате, если применимо.
  • Отозвать согласие, когда обработка основана на согласии.
  • Обратиться в компетентный надзорный орган.

Отзыв согласия не влияет на законность обработки, выполненной до его отзыва.

11. Удаление данных

Пользователь может запросить удаление персональных данных, связанных с его аккаунтом Founders Launcher.

Для подачи запроса необходимо обратиться по контактному адресу, указанному в разделе «Контакты».

Перед выполнением запроса может потребоваться проверка принадлежности аккаунта заявителю. Для такой проверки не требуется сообщать пароль Discord.

Запрос рассматривается в сроки, предусмотренные применимым законодательством.

Некоторые сведения могут сохраняться после удаления аккаунта, если это необходимо для исполнения юридических обязательств или защиты законных прав.

Удаление данных Founders Launcher само по себе не приводит к удалению аккаунта Discord.

12. Несовершеннолетние пользователи

Использование Founders Launcher предполагает соблюдение возрастных требований Discord и применимого законодательства.

Если для обработки данных несовершеннолетнего пользователя необходимо согласие законного представителя, такое согласие должно быть получено в предусмотренных законом случаях.
